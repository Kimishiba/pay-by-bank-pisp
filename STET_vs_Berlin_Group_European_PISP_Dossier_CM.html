Strategic Executive Finding
Under PSD2, continental Europe divided along geopolitical lines into two dominant standards: Berlin Group NextGenPSD2 across Germany, the Netherlands, and domestic Belgium; and STET PSD2 across 95%+ of France.

Building a single STET adapter in the CM.com Gateway unlocks virtually the entire French retail market (BNP Paribas, Crédit Agricole, Société Générale, BPCE, and Crédit Mutuel) without bespoke bilateral integration for each bank. With our existing Berlin Group engine and a companion STET engine, CM Payments B.V. achieves direct, intermediary-free coverage of over 85% of Western European consumer bank accounts using a single pair of eIDAS certificates.

Comparative Architecture: Berlin Group vs. STET

The table below highlights the architectural differences between the Berlin Group NextGenPSD2 and French STET PSD2 specifications:

Technical Dimension Berlin Group NextGenPSD2 STET PSD2 Standard Gateway Engineering Implication
Primary Geography Germany (~100%), Netherlands (~90%+), Austria, Belgium (~70%) France (~95%), French overseas territories, parts of Belgium BIC-based routing table dispatches to dialect handler.
Payment Initiation Path POST /v1/payments/sepa-credit-transfers POST /payment-requests Target endpoint URL mapped dynamically.
Status Inquiry Path GET .../sepa-credit-transfers/{id}/status GET /payment-requests/{id} Normalized transaction status mapper.
Payload Structure Flat ISO 20022 JSON fields (instructedAmount, creditorAccount) Nested STET JSON (initiatingParty, beneficiary, creditTransferTransaction) Separate Go structs for wire serialization.
Request Signing JWS (RFC 7515) or Cavage HTTP Signature STET-profile HTTP Signature Signed with the same corporate eIDAS QSealC.
Transport Security Mutual TLS (mTLS) with eIDAS QWAC Mutual TLS (mTLS) with eIDAS QWAC Identical network transport handshake layer.
SCA Redirect Format _links.scaRedirect.href _links.consentApproval.href Normalized redirect URL handed off to checkout UI.

Strategic Engineering Roadmap for CM Payments B.V.

Action Plan
Three targeted technical execution steps for sovereign European scale:
  • Maintain Berlin Group Engine: Keep our existing Go core actively deployed. It immediately covers 100% of Germany and 90%+ of the Netherlands with zero per-transaction fee overhead.
  • Implement Modular STET Adapter: Add adapters/stet to serialize into /payment-requests. One single STET adapter will cover BNP Paribas, Crédit Agricole, Société Générale, and BPCE.
  • Universal eIDAS Cryptographic Passport: Continue using our single eIDAS QWAC and QSealC certificate pair issued to CM Payments B.V., which satisfies both Berlin Group and STET security mandates.
